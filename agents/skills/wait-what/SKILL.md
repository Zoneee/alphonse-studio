Wait, I don't understand where you've got to here. Re-pitch that.

Before re-pitching, run two passes:

1. **Call the Skill tool for `grilling`** — surface what's actually unclear: what assumptions did the last message carry that I haven't verified, and which terms am I using loosely?
2. **Call the Skill tool for `domain-modeling`** — align vocabulary: am I using the right terms? Does the repo's `CONTEXT.md` (follow `CONTEXT-MAP.md` to the right one if the repo has multiple) have a sharper word?

Then re-pitch: give me a little bit of context, talk in ASD-STE100 Simplified Technical English, and use the ubiquitous language from `CONTEXT.md`.
